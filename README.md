# AI 協作教學作品集

與 AI 協作做出來的教學工具，依「備課 → 上課 → 評量」整理。有網址的作品點一下就能打開。

線上版：https://peicheng0413.github.io/ai-teaching-cases/

- 單一 `index.html`，零依賴。作品資料集中在檔案下方的 `WORKS` 陣列，新增或修改作品只要改那裡。
- 截圖在 `shots-web/`（1600 寬 JPEG）；影片在 `media/`，用瀏覽器內建播放器播放。
- 本機預覽：`python3 -m http.server 8790`，開 http://localhost:8790/（直接雙擊 HTML 檔，影片可能無法播放）。

GitHub Pages 從 `main` 分支根目錄發布，push 後自動上線。
